# 🚀 Installation Rapide / Quick Installation

## 🇫🇷 Français

### Installation en 3 clics :

1. **[Cliquez ici pour installer Tampermonkey](https://www.tampermonkey.net/)** (extension navigateur)
   
2. **[Cliquez ici pour installer GotaMod](https://cdn.jsdelivr.net/gh/collardmath57-oss/gotamod@latest/gotamod.user.js)** ⭐
   
3. **Visitez [gota.io](https://gota.io)** et faites un clic droit pour changer de joueur !

✅ **C'est tout !**

### Besoin d'aide ?
📖 [Guide d'installation complet en français](INSTALLATION_FR.md)

## 💡 Problèmes Communs / Common Issues

### 🇫🇷 Le script ne fonctionne pas ?
1. Vérifiez que Tampermonkey est activé (icône colorée)
2. Rechargez la page gota.io (F5)
3. Vérifiez la console (F12) pour les messages [GotaMod]

### 🇬🇧 Script not working?
1. Check that Tampermonkey is enabled (colored icon)
2. Reload gota.io page (F5)
3. Check console (F12) for [GotaMod] messages
