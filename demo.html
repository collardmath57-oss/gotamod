🎮 GotaMod v2.0

Dual Player - Same Server Edition

🎯 What Makes This Special?

BOTH PLAYERS ON THE SAME SERVER! Unlike other mods that open two separate browser windows or tabs, GotaMod v2.0 connects TWO players to the SAME game server. This means you control two players in the SAME match, on the SAME server, in the SAME game world. Perfect for gota.io/camlan and all other gota.io servers!

🔗

Same Server

Both Player 1 and Player 2 connect to the exact same game server. No separate sessions!

🖱️

Right-Click Switch

Instantly switch between Player 1 (left) and Player 2 (right) with a simple right-click.

🎨

Visual Indicators

Green border for Player 1, red border for Player 2. Always know who you're controlling.

⚡

Real Dual Control

True WebSocket hook creates two actual game connections. Both players are real!

📥 Installation

  1. Install Tampermonkey browser extension
  2. Open Tampermonkey dashboard and create a new script
  3. Copy the code from gotamod.user.js in this repository
  4. Paste into Tampermonkey and save (Ctrl+S)
  5. Go to gota.io/camlan and start playing!
