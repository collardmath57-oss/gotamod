Installation

Method 1: Tampermonkey Script

  1. Install Tampermonkey browser extension
  2. Click on Tampermonkey icon → "Create new script"
  3. Copy the content of gotamod-dual-player.user.js
  4. Save and enable the script
  5. Visit gota.io and enjoy!

Method 2: CDN Injection

var script = document.createElement('script');
script.src = 'https://your-cdn.com/gotamod-inject.js';
document.head.appendChild(script);

How It Works

GotaMod creates two iframe instances of gota.io side by side on a single page. The active player has a colored border and full opacity, while the inactive player is slightly dimmed. You can instantly switch between controlling each player using the right mouse button.

Note: This is purely an aesthetic and control enhancement. It doesn't modify game mechanics or provide unfair advantages.
