## [1.0.0] - 2026-02-03

### Added
- Initial release of GotaMod
- Dual player control system for gota.io
- Right-click switching functionality
- Visual indicator with color-coded borders
- Keyboard shortcuts (Tab, 1, 2)
- CDN integration via jsDelivr
- Comprehensive documentation suite:
  - README.md - Main documentation
  - INSTALLATION.md - Installation guide
  - CONTRIBUTING.md - Contribution guidelines
  - QUICK_REFERENCE.md - Quick reference card
  - PROJECT_SUMMARY.md - Technical overview
- Interactive test demo page
- Installation landing page
- MIT License
- Project metadata (package.json)
- Git ignore rules

### Features
- WebSocket interception for dual connections
- Seamless player switching
- Non-intrusive aesthetic enhancement
- Zero data collection
- Open source and auditable
- Cross-browser compatibility
- Automatic updates via Tampermonkey
- Public API for advanced users

### Technical Details
- Script size: 6.5KB (unminified), 2.5KB (minified)
- No external dependencies
- Event-driven architecture
- Minimal performance impact
- Standards-compliant JavaScript
- Security-audited (CodeQL)

- 1000+ lines of documentation
- Step-by-step installation guides
- Interactive demos
- API reference
- Troubleshooting guides
