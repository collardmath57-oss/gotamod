🎮 GotaMod

Contrôleur Dual Player pour Gota.io

⚡ Installation en 2 clics

Suivez ces étapes simples pour installer GotaMod

1

Installer Tampermonkey

Tampermonkey est une extension gratuite qui permet d'exécuter des scripts utilisateur.

📥 Installer Tampermonkey

2

Installer GotaMod

Une fois Tampermonkey installé, cliquez sur ce bouton :

⭐ Installer GotaMod

Tampermonkey s'ouvrira automatiquement. Cliquez simplement sur "Installer".

✅ C'est terminé !
Visitez gota.io et faites un clic droit pour changer de joueur !

🎮 Contrôles

Clic Droit Changer entre Joueur 1 et Joueur 2
Tab Méthode alternative pour changer
1 Sélectionner le Joueur 1
2 Sélectionner le Joueur 2
💡 Astuce : Maintenez Shift + Clic Droit pour afficher le menu contextuel normal du navigateur.

⚡ Install in 2 Clicks

Follow these simple steps to install GotaMod

1

Install Tampermonkey

Tampermonkey is a free extension that allows you to run userscripts.

📥 Install Tampermonkey

2

Install GotaMod

Once Tampermonkey is installed, click this button:

⭐ Install GotaMod

Tampermonkey will open automatically. Simply click "Install".

✅ You're done!
Visit gota.io and right-click to switch players!

🎮 Controls

Right Click Switch between Player 1 and Player 2
Tab Alternative switching method
1 Select Player 1
2 Select Player 2
💡 Tip: Hold Shift + Right Click to show the normal browser context menu.
