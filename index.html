🎮 GotaMod

Dual Player Controller for Gota.io

🎯 Dual Player Control

Manage two players simultaneously on one page instead of juggling multiple windows.

🖱️ Right-Click Switching

Seamlessly switch between players with a simple right-click gesture.

👁️ Visual Indicator

Always know which player is active with clear color-coded indicators.

⌨️ Keyboard Shortcuts

Additional control with Tab and number keys for quick switching.

📦 Installation

Choose your preferred installation method:

Install via Tampermonkey View on GitHub

CDN Injection

Or inject directly via CDN:

<script src="https://cdn.jsdelivr.net/gh/collardmath57-oss/gotamod@latest/gotamod.min.js"></script>

🎮 Controls

Right Click Switch between Player 1 and Player 2
Tab Alternative method to switch players
1 Directly select Player 1
2 Directly select Player 2
Shift + Right Click Show normal context menu

✨ How It Works

  1. Install the Tampermonkey extension in your browser
  2. Click the installation link above to add GotaMod
  3. Visit gota.io and the script will automatically activate
  4. You'll see an indicator in the top-right corner
  5. Right-click anywhere to switch between players
  6. Enjoy controlling two players from one page!

🔧 API Reference

For advanced users, GotaMod provides a JavaScript API:

// Switch to the other player window.GotaMod.switchPlayer(); // Set active player directly window.GotaMod.setActivePlayer(1); // or 2 // Get current active player window.GotaMod.getActivePlayer(); // returns 1 or 2 // Access configuration window.GotaMod.config;
