🎮 GotaMod - Dual Player Control for Gota.io

About GotaMod

GotaMod is a Tampermonkey userscript that allows you to control two players simultaneously on a single page in gota.io. Switch between players with a simple right-click and manage both game instances efficiently.

🎮 Dual Player Control

Control two game instances on one page, eliminating the need for multiple browser windows.

🖱️ Easy Switching

Switch between Player 1 and Player 2 instantly with a right-click.

🎨 Visual Indicators

Clear colored borders (green/red) show which player is currently active.

⚡ High Performance

Optimized event routing ensures smooth gameplay for both players.

🌐 CDN Support

Advanced version with CDN-hosted injection code for enhanced features.

🔧 Easy Setup

Simple installation via Tampermonkey - no complex configuration needed.

📋 Installation Instructions

  1. Install Tampermonkey browser extension
  2. Click on one of the script links below to open the raw script
  3. Copy the entire script content
  4. Open Tampermonkey dashboard and create a new script
  5. Paste the script content and save (Ctrl+S or Cmd+S)
  6. Navigate to gota.io
  7. The page will automatically split into two game instances
  8. Use right-click to switch between Player 1 (green) and Player 2 (red)

🎯 How to Use

Player 1 (Left Side): Shows a green border when active
Player 2 (Right Side): Shows a red border when active
Right-Click Anywhere: Switch between players
Mouse & Keyboard: Automatically routed to the active player
Top Indicator: Shows which player is currently active
